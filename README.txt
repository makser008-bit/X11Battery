X11 Battery Tray - версія 0.8.1
================================
English version: README_EN.txt


ПРО ПРОГРАМУ
------------
X11 Battery Tray - невелика програма для Windows, яка показує заряд акумулятора і поточний DPI
ігрової миші ATTACK SHARK X11 прямо на панелі завдань, поряд із системним треєм:

    [DPI: 800] [мишка 93%] ^

Програма читає дані безпосередньо з 2.4 GHz донгла мишки і не потребує фірмової програми:
запустив один раз - і числа завжди перед очима. Вона працює у фоні, стартує разом з Windows,
підлаштовується під тему Windows (темна/світла), мову системи та масштаб екрана і розрахована
на мінімальне навантаження. Інтерфейс - у стилі Windows 11.

Що вміє:
  * показувати заряд мишки у відсотках (з індикацією зарядки і низького заряду);
  * показувати поточний DPI (кількість точок, а не номер ступеня) - окремим віджетом, який можна вимкнути;
  * запам'ятовувати останній ступінь DPI, навіть якщо ПК вимкнули;
  * працювати на двох моніторах (на вибір), мати закріплення положення і кнопку скидання;
  * автоматично говорити мовою Windows (вбудовано 23 мови, можна додати свою);
  * мати власну іконку (логотип Attack Shark).


ЩО ПОКАЗУЄ
----------
ВІДЖЕТ ЗАРЯДУ (праворуч, біля трея) - іконка мишки і заряд у відсотках, напр. "93%".
  * звичайний стан - колір тексту як у теми Windows (світла або темна тема)
  * 15% і менше - червоний
  * мишка заряджається - зелений, зі значком блискавки
  * 15 секунд немає даних (мишка спить або вимкнена) - сірий, показується останнє відоме значення

ВІДЖЕТ DPI (лівіше від віджета заряду) - напр. "DPI: 800". Можна вимкнути в меню.
  Мишка повідомляє програмі лише НОМЕР ступеня DPI, а не саме значення, тому число береться з
  таблиці, яку ти один раз вводиш (див. "Налаштування DPI"). Поки для ступеня значення не задано -
  показується "DPI: --".

ПІДКАЗКА при наведенні курсора (з'являється через ~0,4 с; малюється самою програмою: заокруглена, без білої
рамки, підлаштовується під тему - у темній темі темна, у світлій з тонкою сірою рамкою):
  * на віджеті заряду - два рядки: "ATTACK SHARK X11: 93%" (+ "(заряджається)") і "DPI: 800"
  * на віджеті DPI - "DPI: 800"

ШРИФТ - Segoe UI Variable Text (як у меню Пуск Windows 11); якщо його немає - Segoe UI.
Віджети прозорі (без фону), згладжені і адаптуються до масштабу екрана.

Окремої іконки в системному треї немає. Меню відкривається ПРАВОЮ кнопкою миші по віджету.


МЕНЮ
----
Права кнопка миші на будь-якому віджеті відкриває меню (лівий клік нічого не робить, лише перетягування).
Меню у стилі Windows 11: підлаштовується під тему Windows (темна/світла, як меню панелі завдань)
і має іконки Segoe Fluent Icons. Увімкнені перемикачі позначаються галочкою в кінці рядка (справа).
Пункти:
  * два сірих рядки: поточний заряд і DPI
  * Запускати разом з Windows - автозапуск
  * Показувати DPI біля трея - показати/сховати віджет DPI
  * Закріпити положення - забороняє переміщення віджетів
  * Скинути положення - повернути віджети в початкове місце біля трея
  * Монітор для віджетів - підменю (з'являється лише коли підключено 2+ монітори)
  * Налаштувати значення DPI... - вікно з 6 полями
  * Мова / Language - автоматично (мова Windows) або вибір вручну
  * Версія (інформаційний рядок)
  * Вихід

Віджет заряду показується завжди: через нього відкривається меню.


НАЛАШТУВАННЯ DPI
----------------
У X11 6 ступенів DPI. Щоб віджет показував число, один раз вкажи значення своїх ступенів:

  Меню > "Налаштувати значення DPI..."

Відкриється вікно з 6 полями ("Ступінь 1" ... "Ступінь 6"; темне, якщо тема Windows темна):
  * впиши DPI для кожного ступеня (значення дивись у фірмовій програмі Attack Shark)
  * порожнє поле = значення для цього ступеня не задано
  * допустимі значення: від 1 до 100000
  * "Зберегти" (Enter) - застосувати, "Скасувати" (Esc) - закрити без змін, Tab - наступне поле
Зміни застосовуються одразу, перезапуск не потрібен.

Значення зберігаються у файлі dpi.txt поруч з програмою (рядки вигляду "1 = 400"). Файл можна
редагувати і вручну, рядки з # ігноруються; зміни підхоплюються самі за кілька секунд.

Ступінь DPI мишка надсилає лише в момент натискання кнопки DPI. Тому програма запам'ятовує
останній ступінь і показує його після перезапуску ПК. Якщо ти змінив DPI, поки програма не
працювала (наприклад, мишка була підключена до іншого пристрою), показаний DPI буде застарілим -
просто натисни кнопку DPI один раз.


ПОЛОЖЕННЯ ВІДЖЕТІВ
------------------
* Перетягування: затисни ліву кнопку миші на віджеті і тягни вліво/вправо. Обидва віджети
  рухаються разом, положення запам'ятовується.
* Межі: віджети не можуть заїхати за край - праворуч вони впираються в трей, ліворуч у край
  панелі завдань.
* "Закріпити положення" забороняє перетягування (меню по правій кнопці працює).
* "Скинути положення" повертає початкове положення (навіть коли положення закріплене).
* Монітор: "Монітор для віджетів" переносить віджети на панель завдань обраного монітора.
  Вибір запам'ятовується, для кожного монітора положення окреме.
  - Для додаткового монітора в Windows має бути увімкнено "Показувати панель завдань на всіх
    дисплеях" (Параметри > Персоналізація > Панель завдань > Поведінка панелі завдань). Якщо
    панелі на моніторі немає, пункт у меню неактивний, а віджети лишаються на основному.
  - На додатковій панелі трея немає (лише годинник), тому початкове положення там - ліворуч від
    годинника на оцінений відступ. За потреби просто перетягни віджети.


МОВА ІНТЕРФЕЙСУ
---------------
Мова визначається автоматично за мовою інтерфейсу Windows (з її списку пріоритетних мов):
українська Windows - українська програма, японська - японська і т.д.
Вбудовано 23 мови: English, Українська, Русский, Polski, Deutsch, Français, Español, Português,
Italiano, Nederlands, Türkçe, Čeština, Română, العربية, עברית, हिन्दी, ไทย, Tiếng Việt,
Bahasa Indonesia, 日本語, 한국어, 简体中文, 繁體中文. Якщо мови Windows серед них немає - англійська.
Арабська та іврит відображаються справа наліво (дзеркальний інтерфейс).

Змінити вручну: меню > "Мова / Language" > обрати мову. Пункт "Авто" повертає мову Windows.
Вибір зберігається і діє одразу (без перезапуску).

Що перекладається: меню, підказки, вікно значень DPI, коментарі у файлі dpi.txt.
Що не перекладається: написи на самих віджетах (число, % та "DPI" однакові всюди), README, build_exe.bat.

Додати свою мову (без перезбирання програми):
  1) у папці lang поруч з X11Battery.exe скопіюй _template.json у файл lang\xx.json,
     де xx - код мови (sr, hu, sv, pt-BR тощо);
  2) переклади значення (плейсхолдери {n}, {pct}, {v}, {menu} не змінюй), у "_name" впиши назву мови;
  3) перезапусти програму - мова з'явиться в меню "Мова / Language" і, якщо збігається з мовою Windows,
     буде вибрана автоматично.
Такий файл також може виправити окремі рядки вбудованої мови (він має пріоритет над вбудованим).
Переклади вбудованих мов зроблено автоматично і не перевірялися носіями мов - знайдені неточності
можна виправити саме так.


АВТОЗАПУСК
----------
Автозапуск вмикається сам при першому запуску. Вимкнути/увімкнути - галочка в меню.
Друга копія програми не запускається.
Якщо перенесеш exe в іншу папку - вимкни і знову увімкни автозапуск у меню, щоб він вказував на нове місце.


ВИМОГИ
------
* Windows 10/11 (віджети розраховані на панель завдань Windows 11; підтримується лише
  горизонтальна панель - знизу або зверху).
* Мишка підключена через 2.4 GHz донгл (VID 1D57, PID FA60).
* Фірмову програму Attack Shark краще закрити (вона може перехоплювати звіти мишки).
* Для збірки exe - Python 3 з python.org (з галочкою Add to PATH) та інтернет для встановлення PyInstaller.
  Сама програма використовує лише стандартну бібліотеку Python + ctypes, без сторонніх пакетів.


ФАЙЛИ
-----
x11_battery.py       - сама програма
build_exe.bat        - збирає X11Battery.exe (PyInstaller) і кладе його поруч; після збірки видаляє
                       тимчасові папки build і dist
version_info.txt     - версія, яку видно у властивостях exe (Властивості > Докладно)
X11Battery.ico       - іконка програми (логотип Attack Shark): іконка exe та вікна налаштування DPI.
                       Щоб змінити іконку - заміни цей файл і збери exe заново (build_exe.bat).
lang\_template.json  - шаблон для додавання власної мови (див. "Мова інтерфейсу")
x11_scan.py          - допоміжний сканер HID, потрібен лише для діагностики
README.txt           - цей файл (українською)
README_EN.txt        - опис англійською

Що програма створює під час роботи:
dpi.txt                          - поруч з програмою: значення DPI для ступенів
x11_battery.log                  - поруч з програмою: з'являється лише якщо сталася помилка
%APPDATA%\X11Battery\state.json  - останній відомий ступінь DPI
Реєстр HKCU\Software\X11Battery  - налаштування: віджет DPI показувати чи ні, закріплення,
                                   обраний монітор, мова, положення (окремо для кожного монітора)
Реєстр HKCU\...\Run              - запис автозапуску (значення X11Battery)


ЗАПУСК І ЗБІРКА
---------------
Тест:       python x11_battery.py   (або pythonw x11_battery.py - без консолі)
Постійно:   запусти build_exe.bat (потрібен Python 3) - з'явиться X11Battery.exe поруч; користуйся ним.
Оновлення:  просто запусти build_exe.bat ще раз - він сам закриє стару програму і збере нову.
Під час збірки у вікні має з'явитись рядок "Іконка: X11Battery.ico знайдена, додаю в exe".
Якщо exe перенести в іншу папку, dpi.txt (і папку lang, якщо вона є) теж треба перенести разом з ним.
Якщо папка з exe захищена від запису (наприклад, Program Files), dpi.txt не збережеться -
тримай exe у звичайній папці.

Видалення: меню > Вихід; вимкни автозапуск (галочка в меню, до виходу) і видали файли програми.
За бажанням видали ще папку %APPDATA%\X11Battery і розділ реєстру HKCU\Software\X11Battery.


ЯК ЦЕ ПРАЦЮЄ (ТЕХНІЧНО)
-----------------------
Програма читає input-звіти інтерфейсу донгла з usage page 0x0A (MI_02 COL03) напряму через
SetupAPI і hid.dll (чистий ctypes, без hidapi):
  03 55 40 <стан> <заряд>   - приходить приблизно кожні 2 секунди
        стан:  01 - звичайна робота, 03 - зарядка (біт 0x02)
        заряд: 0-100 (%)
  03 55 10 <ступінь> 00     - приходить при натисканні кнопки DPI (ступінь рахується з 1)
Формат виведено з логів сканера, офіційної документації немає. Віджети - це прозорі (піксельна
прозорість) дочірні вікна панелі завдань Shell_TrayWnd / Shell_SecondaryTrayWnd. Темна тема меню
і вікна DPI використовує недокументовані можливості Windows (uxtheme) і DWM; підказка - власне
прозоре вікно програми.
Якщо на якійсь прошивці відображення не збігається з фірмовою програмою - запусти
python x11_scan.py listen 40 і надішли лог.


ОБМЕЖЕННЯ
---------
* Працює лише через донгл. Через Bluetooth або кабель інтерфейс і звіти можуть бути іншими.
* Ознака зарядки (біт 0x02) і нумерація ступенів DPI з 1 виведені з тестів, не з документації.
* Мишка не повідомляє саме значення DPI, лише номер ступеня - тому значення вводяться вручну.
* Віджети не тестувались на всіх збірках Windows 11 та всіх конфігураціях моніторів.
* Тема меню й вікна DPI перемикається недокументованими функціями Windows. Якщо на якійсь
  збірці вони не діють, елементи лишаються в системному вигляді (працюють, але без темної теми).
  Іконки меню потребують шрифту Segoe Fluent Icons (є в Windows 11); без нього використовується
  Segoe MDL2 Assets (Windows 10).
* Переклади вбудованих мов не перевірялися носіями мов.


ДІАГНОСТИКА
-----------
* Щось виглядає неправильно - зроби скріншот.
* Віджетів не видно: перевір, що мишка підключена через донгл і програма запущена (Диспетчер завдань);
  правою кнопкою по віджету > "Скинути положення"; розгорни x11_battery.log, якщо він є.
* Іконка exe не змінилась: 1) X11Battery.ico має лежати поруч з build_exe.bat - під час збірки у вікні має
  з'явитись рядок "Іконка: X11Battery.ico знайдена"; 2) збери exe заново (не користуйся старим);
  3) Windows кешує іконки - батнік скидає кеш сам, але якщо стара іконка лишилась, перезапусти Провідник
  (Диспетчер завдань > Провідник > Перезапустити) або скопіюй exe під іншою назвою;
  4) у Властивості > Докладно має бути актуальна версія.
* Помилки пишуться в x11_battery.log поруч з програмою (файл з'являється лише при помилці).
* Сканер: python x11_scan.py (список інтерфейсів), python x11_scan.py feature, python x11_scan.py listen 40
  (звіти мишки; рухай мишу, тисни DPI, підключай зарядку). Лог пишеться в x11_scan_log.txt.
